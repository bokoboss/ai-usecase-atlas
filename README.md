# AI Use Case Atlas

ค้นหาว่า AI ช่วยงานของคุณได้อย่างไร

A task-first AI adoption library for Transportation BU: **450 use cases + 500 quick ideas**, covering daily work, Office, engineering, AutoCAD/Civil 3D/Revit, VISSIM, coding/automation, PM, proposal work and management.

## Product direction
- Start from **the work users are doing**, not AI terminology.
- Search in Thai/English and filter by role, software, work category and AI maturity level.
- Every use case includes a **Prompt Starter** and a visible **Human / Engineering Check**.
- v1 is static-first: no paid API or database required.
- Architecture is prepared for a future PostgreSQL/Supabase + semantic-search backend.

The initial web-app scaffold and product architecture are being added in this repository.
