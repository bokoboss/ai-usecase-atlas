# Content Consolidation — Phase 2

**Date:** 2026-09-24

Phase 2 reduces catalogue clutter without deleting source records.

## Runtime grouping

The search result list collapses manually reviewed near-duplicate pairs/groups. The highest-ranked item for the current query/filter remains visible. Other records stay addressable by ID, remain usable from Quick Ideas, and appear as **Similar Variants** inside the detail panel.

## Related-case strategy

Related cases now prioritize:
1. same discipline/category,
2. shared software/tags/context,
3. the next higher AI maturity level,
4. a different task rather than a near-duplicate variant.

The aim is to make the detail panel suggest a plausible **next workflow**, not simply another card with similar wording.

## Readability pass

The UI typography was raised across navigation, filters, cards, metadata, detail content, prompts, workflow steps, Quick Ideas, Related Cases and mobile navigation. Very small 8–11 px interface text is no longer the default for normal reading content.
